# Program Counter

## Description

The PROGRAM_COUNTER stores the address of the current instruction and provides it to the Instruction Fetch (IF) stage.

The PC is updated at the positive edge of the clock when pc_write is enabled. It can also hold its current value during a pipeline stall.

## Inputs and Output

| Signal | Width | Description |
|--------|------:|-------------|
| clk | 1-bit | Processor clock |
| reset | 1-bit | Resets the Program Counter |
| pc_write | 1-bit | Enables PC update |
| pc_next | 32-bit | Next instruction address |
| pc | 32-bit | Current Program Counter value |

## Operation

During normal execution, pc_write is enabled and the Program Counter loads pc_next at each positive clock edge.

The next address is normally generated by the PC Adder as pc + 4.

This produces the sequential address progression:

0 → 4 → 8 → 12 → 16

## Pipeline Stall

The pc_write signal is controlled by the Hazard Detection Unit.

When a load-use hazard is detected, pc_write is disabled. The Program Counter then retains its current value instead of loading pc_next.

Holding the PC prevents a new instruction from being fetched while the pipeline is stalled.

## Branch Handling

The Program Counter does not calculate the branch target itself.

The top-level processor selects pc_next from either the sequential address or the calculated branch target.

When a branch is taken, the branch target is selected and loaded into the Program Counter at the next positive clock edge.

## Reset Behavior

When reset is asserted, the Program Counter is cleared to zero.

After reset is released, instruction execution begins from address zero in Instruction Memory.
