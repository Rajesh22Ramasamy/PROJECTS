# Data Memory Module

## Description

The Data Memory module provides storage for load and store instructions in the pipelined RISC-V processor.

The current implementation supports LW and SW instructions. The memory contains 256 locations, with each location storing one 32-bit word, giving a total capacity of 1 KB.

## Inputs and Output

| Signal | Width | Description |
|--------|-------|-------------|
| clk | 1-bit | Clock used for memory write operations |
| mem_read | 1-bit | Enables memory read |
| mem_write | 1-bit | Enables memory write |
| address | 32-bit | Memory address generated by the ALU |
| write_data | 32-bit | Data to be written during SW |
| read_data | 32-bit | Data read from memory |

## Memory Organization

The memory contains 256 locations with a width of 32 bits per location.

Since each location represents one 32-bit word, address[9:2] is used as the memory index.

The lower two address bits are not used for word selection because each word occupies 4 bytes.

## Read and Write Operation

Memory read is combinational. When mem_read is enabled, the data from the selected memory location is provided through read_data. When mem_read is disabled, read_data is set to zero.

Memory write is synchronous. When mem_write is enabled, write_data is stored in the selected memory location at the positive clock edge.

For LW and SW instructions, the ALU calculates the memory address using:

address = rs1 + immediate

For SW, the value from rs2 is passed as write_data. For LW, the value read from Data Memory is passed through the MEM/WB pipeline register before being written back to the Register File.

## Verification

The module was verified using a Verilog testbench by performing read and write operations at different memory locations.

The testbench checks:

- Reading previously written data
- Writing to different memory locations
- Independent storage of values at different locations
- No memory modification when mem_write is disabled
- read_data is zero when mem_read is disabled

The expected values were observed for the tested memory operations.
