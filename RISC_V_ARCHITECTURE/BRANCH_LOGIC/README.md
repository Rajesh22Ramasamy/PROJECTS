# Branch Logic

## Description

The Branch Logic module handles the branch decision and target address calculation for the BEQ instruction.

It uses the branch control signal from the Main Control Unit and the zero flag generated by the ALU to determine whether the branch should be taken.

## Inputs and Outputs

| Signal | Width | Description |
|--------|-------|-------------|
| pc | 32-bit | PC of the current branch instruction |
| immediate | 32-bit | Sign-extended branch immediate |
| branch | 1-bit | Branch control signal from the Main Control Unit |
| zero | 1-bit | Zero flag generated by the ALU |
| branch_target | 32-bit | Calculated branch target address |
| branch_taken | 1-bit | Indicates whether the branch is taken |

## Working

For a BEQ instruction, the ALU compares the two source register values using subtraction.

If both register values are equal, the ALU result becomes zero and the zero signal is asserted.

The branch decision is:

branch_taken = branch & zero

The branch control signal ensures that a zero result from a non-branch instruction does not cause a branch.

The target address is calculated as:

branch_target = pc + immediate

The immediate value is already sign-extended by the Immediate Generator. This allows the same addition operation to handle both forward and backward branch offsets.

When branch_taken is asserted, branch_target is selected as the next PC instead of the normal PC + 4.

## Pipeline Behavior

The branch decision is made in the EX stage using the PC, immediate value, branch control signal and ALU zero flag.

Since the following instructions may already have entered the pipeline when the branch decision is made, those instructions are flushed when a branch is taken.

## Verification

The module was verified using a Verilog testbench covering:

- Normal non-branch operation
- Zero ALU result for a non-branch instruction
- BEQ with equal and unequal register values
- Forward branch target calculation
- Backward branch target calculation using a negative immediate

The branch_taken and branch_target outputs were checked for each test condition.
